AStrategy LabREBUILDS /STRATEGIES · CREDITS METERED
Flows. Browse catalog (66 strategies + 12 themes) → detail → backtest config → results. Build-your-own: rule builder → validate → backtest → save → promote to ForwardRun (→ C).
Screens. ① Catalog — filter rail (theme/indicator/risk), cards show REAL computed stats or an explicit "not yet backtested" state (never fake numbers). ② Detail — rules in plain English with a code-view toggle (the typed DSL), historical runs list. ③ Backtest config — period/universe/costs presets, CreditChip on Run, cost estimate line. ④ Results — equity curve vs NIFTY, drawdown chart, metrics table (CAGR · Sharpe · Deflated Sharpe · max DD · win rate · turnover · costs paid), walk-forward panel, OverfitBadge (green/amber/red from CPCV/PBO) opening a beginner-language explainer sheet ("this strategy may look better than it is — here's the test we ran"). ⑤ Builder — left palette (indicators/filters/sizing), center canvas of condition rows (IF RSI(14) < 30 AND …), right live-validation panel; invalid rules block the Run button with the reason inline. ⑥ My strategies — table with LifecycleBadge chips.
States. Loading: skeleton curve + shimmering metrics. Empty: "no strategies yet — start from a theme". Error/partial: DataGapBanner per missing data range. Gated: backtests cost credits (FREE teaser = 1/mo on NIFTY-50 universe only).
Copy. Every result footer: "Historical simulation including costs — not indicative of future returns." Sentence case; verbs not hype ("ran 2,140 trades", never "beats the market").
BAI Hedge-Fund Analyst BoardFLAGSHIP · EDITORIAL MAGAZINE PANEL
Flows. Pick symbol (search or from holdings) → pick board (default 5: Buffett, Lynch, Burry, Damodaran, Jhunjhunwala; 13 for PRO) → confirm CreditChip → live progress → board view → export/share.
Screens. ① Setup — symbol picker with "you hold this" tag; persona tiles (portrait-style initial tiles, ±3° rotation, one-line philosophy each); locked personas show GateInline. ② Progress — personas "thinking" as a newsroom: each tile flips to "reading annual report…", staggered. ③ Board — masthead ("The INFY Hearing · Jul 20, 9:42 IST"), per-persona VerdictCards (signal bullish/bearish/neutral + conviction 0-100 meter + 2-line thesis in serif italic), bull-vs-bear DebateTranscript (2 rounds, collapsible, speaker-labeled), Risk Manager panel with deterministic numbers only (position-size cap, portfolio-fit vs your concentration), final verdict block with mandatory dissent line ("Burry disagrees: …" — always present, never omitted), share-card export (score + dissent, no personal numbers).
States. FREE teaser = 2 personas / 1 symbol / day with remaining-quota meter. Partial: a persona that failed shows "couldn't finish reading — re-run" not a fabricated verdict. DataGapBanner if filings stale.
Copy. Personas voice presentation, not advice: "Damodaran's framework values this at…", never "buy". Footer: education framing + sources count.
CSignals & ForwardRunPAPER-TRADING SUCCESSOR · SIMULATION-EXPLICIT
Flows. Strategy (from A) → create signal watch → schedule (EOD / intraday, IST) → alert channels; TradingView webhook setup (HMAC URL + test ping); promote strategy → ForwardRun shadow portfolio.
Screens. ① Signals feed — grouped by strategy; status chips NEW / TRIGGERED / EXPIRED; market-hours header ("NSE closes 15:30 · next EOD scan 16:05"). ② Signal detail — price chart with entry marker, the exact rule that fired rendered in plain English + values at trigger. ③ Alert config — per-watch channel toggles, quiet hours. ④ Webhook setup — copy-URL field, HMAC secret reveal, "send test ping" with live green/red result, last-5-pings log (developer-ish but friendly). ⑤ ForwardRun dashboard — hypothetical P&L vs benchmark, per-trade ledger (signal → hypothetical fill incl. costs), divergence-from-backtest indicator (live CAGR vs backtest band; amber outside 1σ). ⑥ ForwardRun list with LifecycleBadges.
States. Empty: "no signals yet — schedule runs tonight 16:05 IST". Missed run: shown as a gap, never interpolated. Execution: a visible seam — "execution: coming later" disabled affordance.
Copy. The word simulation appears on every P&L surface: "hypothetical — no real orders were or can be placed."
