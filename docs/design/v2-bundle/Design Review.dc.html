DESIGN REVIEW · MOBILE APP V2

The old app was screens. The new one is flows.

Review of UseMoney Android/iOS App (65 screens) against stockbook-monorepo, and the rebuild plan. The visual system stays — the information architecture, depth and interactivity change.

01 / WHAT HOLDS UP
  • The visual language — paper, ink borders, hard shadows, gold marker — is faithful to the design system and survives on small screens. Kept as-is.
  • Public surface is complete: onboarding, 11 Clerk auth screens, 10 marketing pages, resources, legal. ~29 screens reused unchanged.
  • Copy voice (period-mid-headline, mono labels, ₹ numbers) is right everywhere.
02 / WHAT THE REPO SAYS IS MISSING
  • Positions — app/positions (58KB client) has no mobile screen at all.
  • No instrument pages. Every list (holdings, screener, movers) dead-ends — the repo's stock/MF detail depth never made it to mobile.
  • Analysis & Compare (app/analysis, app/compare) absent in-app.
  • Sectors (discover/sectors), CSV import wizard (tradebook/import), welcome/first-run (app/welcome) and demo mode all missing.
  • Screens are endpoints, not journeys. Broker connect has no OAuth → syncing → error states; Roast has no run → progress → share; Sage never spends a credit; there is no paywall or checkout anywhere.
03 / THE IA PROBLEM

The old shell copies the desktop sidenav into a drawer — 30 items in 5 groups behind a hamburger — then adds a 5-tab bar that duplicates four of them. That's desktop thinking. Mobile IA should be reach-based: the four things you check daily on the bar, everything else two taps deep with context, not in a catalog.

  • Sage-centric: center tab, plus a Sage strip on every money surface — dashboard, stock page, roast verdict, tax report — with visible credit costs.
  • Portfolio = one place: Holdings · Positions · Tradebook segments, broker filter, pull-to-refresh sync, rows open a holding sheet → full stock page.

  • You = plan & credits, brokers, notifications, settings, help, legal (old marketing/legal pages reused here). No drawer anywhere.
  • Depth over breadth: stock & MF detail pages, holding sheet, trade-pair sheet, compare table — every list row goes somewhere.
  • Flows with states: first-run (onboard → auth → profile → connect broker → sync → ready), broker OAuth incl. token-expiry & error retry, Sage deep research (confirm cost → progress → cited report), Roast (scope → run → score → share card), CSV import (upload → map → review), upgrade (paywall → UPI checkout → success), FIRE scenarios. Loading / empty / error / gated states designed, not implied.
  • New primitives: bottom sheet, toast, segmented control, credit chip, tier-lock, sync pill, global search overlay, coach marks.
05 / BUILT FOR WHAT'S COMING

The v2 IA leaves explicit seams for the 2026H2 roadmap modules, so they bolt on without another rebuild:

  • Strategy Lab (A) → Discover · Strategies slot; lifecycle chips already in the vocabulary.
  • Analyst Board (B) → launches from stock page & Sage composer.
  • Signals / ForwardRun (C) → Discover feed slot + notification patterns.
  • US / NRI (D) → Portfolio is currency-aware; import wizard generalises to statements.
  • Personas (E) → You · Settings section reserved; Home widgets are modular.
  • Memory (F) → Settings transparency center; Sage chips slot exists.
  • Model picker (G) → Sage composer row; credit-multiplier chips reuse the credit chip.

Excluded per direction: paper trading, learning/quiz/tutor.
