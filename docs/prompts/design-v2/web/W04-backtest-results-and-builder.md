## Data wiring
- `LocalEngine.run(dsl, params)` in the `strategy-backtest` worker: daily bars from `DailyPrice`/`Candle` (adjusted), universe membership by date from `IndexConstituent`/`IndexMembership`, indicator kernels ported from `api/backtest/route-logic.ts` + new ones as pure functions in `packages/core/src/quant-lite/` (golden-vector tests per indicator), cost model (brokerage preset + STT + slippage bps) applied per fill, equal-weight sizing with max positions, metrics (CAGR, Sharpe (rf = 0), max DD, win rate, turnover, costs paid, trades, best/worst), walk-forward on fixed 5 splits, NIFTY 50 benchmark from `IndexClose`. Persist downsampled curves (≤ 400 points). `RemoteEngine` returns `ENGINE_UNAVAILABLE` → `Backtest.validation = "unavailable"`.
- Result reads: `getBacktestAction(id, btId)`; trade log paged via `getBacktestTradesAction`.
- Credits: reserve → consume on accept → refund on failure/timeout (600 s job ceiling — see root `CLAUDE.md` "Job throughput"). The old `[id]/backtest/client.tsx` credit charge path is deleted.
- `apps/api`: `POST /v1/strategies/:id/backtests`, `GET /v1/strategies/:id/backtests/:btId`, `GET …/:btId/trades?cursor=` (cursor pagination from `packages/api-utils`), `POST /v1/strategies/validate` (DSL validation for the mobile builder).

## Non-goals
CPCV/PBO/Deflated Sharpe/Monte-Carlo (quant engine); intraday backtests; US universes (until US EOD store + `market` scoping land).

## Acceptance
- Running a backtest on a catalog strategy (e.g. the RSI mean-reversion preset) over NIFTY 100 · 5Y returns costed, benchmarked results that change when the cost preset changes (test on the engine with fixture bars); a backtest with < 30 trades renders the metrics with a `DataGapBanner` "too few trades to trust".
- Indicator kernels match golden vectors; walk-forward folds sum to the full period; equity curve starts at 100.
- Builder: one-rule strategy fails validation with the exact copy; "Create AI" output always passes through validation.
- No credit is consumed when the engine fails (refund proven by a functional test); no `NaN` reaches the UI (finite guards tested).
