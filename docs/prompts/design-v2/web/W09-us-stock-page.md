2. **Chart:** the existing stock-page chart component (`TradingViewAdvancedChart`) mounted with the US listing id and daily resolution only (ranges 1M · 6M · 1Y · 5Y; no intraday resolutions offered). Its data source is whatever A3 has pointed `UDF_BASE_URL` at — the Yahoo-backed `/api/market/udf` until A3 flips, the market-data service tiles after (`MARKET_DATA_TILES`). **Do not add a candles action or route.** Until data-platform B4 lands, the US tile job covers only the `us-interest.ts` set (A2 §3), so a symbol with no tile must render the chart's honest empty state (`DataGapBanner`, copy from the design's empty states) — never a page-level fallback fetch.
