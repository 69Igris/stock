## Data wiring
- `getScreenerScansAction` (new, `scans.ts`): merges `SCAN_CATALOG` + strategy-derived + `listSavedScreensAction` into one `{ id, name, src, plain, rules[], total|null, gate?, degraded? }` list with **yesterday's match count** (cache the last `ScanResult` per scan id; no count → `null`, render `—`). Logic in `scans-rail-logic.ts` (source mapping, ordering, gating) — unit-test.
- `runScanInScreenerAction`: `mapFiltersToScreenFilters` for runnable scans (sync `screenStocksAction`); non-runnable (Chartink/strategy) → existing async `runScanAction`/`runStrategyAction` + status polling; returns the read-only rule chips (plain-English rule strings from the mapping — add `describeScanRules()` in `scans.service.ts`, tested).
- US mode: `screenStocksAction({ market: "US" })` → `screener.service.ts` reads `UsInstrument` + `UsFundamentals`/`UsCompanyFact`/`UsFiling` (filing date for provenance) + `Candle`/`LatestQuote` EOD close; guard with `currentUserMaySeeUsMarket()`. Universe line "4,800 US stocks · EOD" from a count query.
- Saved screens ↔ scans: `saveScreenAction` unchanged; expose YOURS entries in the rail.
- `apps/api` mirror: `GET /v1/scans` returns the merged rail list; `POST /v1/scans/:id/run` unchanged; `POST /v1/screener/stocks` accepts `market`; `GET /v1/saved-screens` unchanged.
- Flags: `screener-v2` (AppFeatureFlag); reads `us-stocks-listing`, `us-stocks-search`.

- Selecting any rail scan renders results in place with read-only chips; "Edit as filters" forks a draft and the saved scan is unchanged (test on the service). Match counts are last-run values or `—`, never invented.
- Typing "undervalued large caps" shows the gold row; applying it charges exactly `CREDIT_COSTS.ai_filter_builder` once and renders an AI context bar.
- US pill absent when the flag is off; on: US rows carry `DelayedDataBadge` + filing column; `$→₹` toggle uses the spot rate + stamp.
- `/discover/scans` redirects under the flag; old URLs with `?mode=`/filters still resolve.
- Visible-control budget: the v2 screener at 1280px has **fewer or equal** top-level controls than legacy (count them in the PR).
