## Build
1. **Stock page (`/stock/[symbol]`):** header from `/v1/market/quotes` (live/delayed provenance → the eyebrow says "LIVE · time IST" only when the envelope says live; else "DELAYED · time IST"), chart from `/v1/market/historical` per range (1D intraday bars if the API serves them — `IntradayBar`; else hide 1D and say so), OHLC + 52W from ratios/technicals; "Your position" from holdings (symbol group) with `HoldingSheet`; tabs: Overview (`/ratios` grid — `—` for absent metrics; about text from `/v1/stocks/:symbol/financials-source`/profile if present), Financials (`/financials` quarterly revenue bars + profitability rows + source/asOf footer), News (`/news/stock/:symbol` + events), My trades (open lots from holdings per broker + closed pairs from `/v1/paired?symbol=`); footer actions: Ask Sage (prefill), Research (→ M14 confirm with `symbol`); star + compare icons; watchlist membership query.
2. **MF page (`/mf/[schemeCode]`):** header tags/NAV from `/v1/discover/mfs/by-scheme-codes`, CAGR tiles from returns, "Your holding" from `/v1/mutualfunds`, overlap card from `/v1/market/fund-composition` (render only when the composition exists and overlap ≥ 15 %), top holdings bars, footer prefill.
3. **Compare (`/compare?symbols=`):** chips (popular from holdings + NIFTY 50 names), 2–3 symbol grid from `/ratios` + `/returns` (best-cell logic in `compare-logic.ts`, tested per row rule: lower P/E better, higher ROE better…), "Ask Sage to pick a winner" → Sage prefill "Compare A vs B for a 3-year hold" (free chat) — the credit-metered `/v1/compare` L3 session is exposed as a secondary "Deep compare ⚡N" action with the confirm sheet.
4. **States:** skeleton header, `DataGapBanner` per tab when the envelope is `empty/fallback`, demo mode data.

- MF overlap card appears only with composition data and ≥ 15 %; top holdings sum ≤ 100 %.
- Compare best-cell rules unit-tested; deep compare never starts without the confirm sheet (credit test).
