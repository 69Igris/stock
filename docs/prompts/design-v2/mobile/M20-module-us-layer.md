## Build
1. **Gating:** `usFlag` = `/v1/me.flags.usStocksListing`; when off, every US route renders `FlagOffScreen` and no US affordance exists anywhere (Home, You, Discover, search, ticker) — one selector `useUsLayer()` consumed by all modules (test).
2. **Fork** (first-run step when flag on; revisitable from Market preferences): writes `PATCH /v1/me/market-preferences {market, residency}`; CTA routes to connect (NRI → link first; LRS → import first) or the India connect screen.
3. **Connect:** cards per persona order; broker tiles from `GET /v1/brokers/us/catalog` (P18 registry incl. per-broker flags/approval-gated tags); tap → consent screen → `POST /v1/brokers/us/connect {broker}` → open the portal URL with `expo-web-browser.openAuthSessionAsync(url, "usemoney://us/callback")` → parse `status`/`connection_id` → sync screen polling `GET /v1/brokers/us/connections` (+ job status) with real counts → done card → "See mixed holdings"; ABANDONED/ERROR → retry sheet; re-auth state from connection status (`BROKEN`) with "Re-authorise" (same flow with `reconnect`). FREE users see the `GateBanner` on Link (paid plans + allowlist only — server-enforced).
4. **Statement import:** document picker (CSV/PDF ≤ 20 MB) → `POST /v1/imports/preview {market:"US"}` (multipart) → mapping list with confidence + row-issue cards (server-provided actions: `useRbiRate`, `mapSymbol`, `skipRow`) → `POST /v1/imports {market:"US", batch, resolutions}` → job poll → review (lots, duplicates, cost pair per persona) → Commit → mixed holdings; LRS persona: "ALSO UPDATED" card → LRS screen.
5. **US stock page** (`/us/stock/[symbol]`): from `/v1/stocks/:symbol/us/*` (header/candles/ratios/financials/insiders/holders/filings) with `EodTag` on every price, dual price via `usPair` (primary from persona), holding line from holdings (US group), Sage CTA gated by `flags.usStockResearch` ("Research · India only today" → toast; on → M14 confirm with `market:"US"`), filing chips open EDGAR URLs in the in-app browser, disclaimer with listing id.
6. **Holdings both markets** (`/us/portfolio`): `GET /v1/holdings?group=market|broker|flat` totals (spot stamp, cost-at-RBI-ref note), US rows → US stock page, India rows → stock page, "ALL INDIA HOLDINGS →" → Portfolio tab.
7. **LRS / TCS** (`/us/lrs`, LRS persona only; NRI sees nothing — the mock's NRI notice card is demo-only): `GET /v1/tax/lrs?fy=` (headroom, TCS claimable, ledger, assumptions), "+ Add" remittance sheet (`POST /v1/tax/lrs/remittances`), Edit assumptions sheet (`PATCH /v1/tax/lrs/assumptions`), export (`GET /v1/tax/lrs/export` → share sheet), disclaimer.
8. **Market preferences** (`/us/prefs`): rows bound to `/v1/me` + `PATCH /market-preferences` (Where do you invest? → fork; Residency toggle; Primary currency; US hours), Connected US accounts (`GET /v1/brokers/us/connections`; re-auth/import rows), "Revoke all US access" (confirm → `DELETE /v1/brokers/us` all), US data disclosure from `GET /v1/me/us-disclosure` (server copy), disclaimer.
9. **Drop-ins owned here** (behind `useUsLayer()`): Home US row (M12), Portfolio US link + US lots (M13), Discover US market card + news chip (M15), Brokers US tiles (M19), Notifications US rows (M19), Tax US card (M18), Risk currency exposure (M18), search US section (M10), Sage suggestion (M14), ticker US items (M10) — each module's prompt references this selector; this prompt wires the data for them.
