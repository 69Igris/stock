- Slash registry parity: `apps/web/lib/chat/*` (commands list served by the API? — if not, add `GET /v1/chat/commands`).

## Build
1. **Chat screen:** empty state per design; conversation via `streamSse("/v1/chat/stream")` rendering `token`s into the active `SageBubble` (throttle re-render to ~30 fps), `block`s as kit-rendered blocks, `tool` events as inline status chips ("reading your tradebook…"), `sources` → `SrcChips`, `followups` → chips, `credits` → update the store; cancel on unmount/back (abort controller); retry on network drop resumes by re-sending (server idempotency via `sessionId` + client message id).
2. **Composer:** input, send (disabled while streaming), model button → `ModelSheet` fed by `/v1/me/composer-preferences` picker models (locked rows for allowlist-gated), `/` opens a commands sheet (`/research`, `/compare`, `/roast`, `/tax`, `/focus`, `/clear`), `@` opens the mention sheet (Recent · Stocks · Funds · Brokers; US pill when flag — same rows/badges as W06), prefill from other screens (`um.sagePrefill`) auto-sends after a short delay as in the mock.
3. **Deep research:** "Research {sym}" and the "Go deeper" card → `POST /v1/research/preview-plan` → `ResearchConfirm` sheet (cost from the estimate, credits after, personalise toggle → `personalise` flag) → `POST /v1/research` → progress screen polling `/status` (steps map from `RunStage` progress; the mock's 5 labels are the mobile phrasing of QUEUED/PLANNING/RESEARCHING/ANALYZING/SYNTHESIZING) → report screen from `/result` blocks; leaving the screen keeps the job running and A01 push/notification deep-links back; out-of-credits sheet when `estimatedCredits > balance` (never call `POST /v1/research` in that case).
4. **Report screen:** verdict/conviction from the result payload (render only if present), TL;DR, sections with source chips (tap → source sheet with title/date/link), meta tags, follow-up (prefill "Follow-up on the {sym} report: …") and "Open {sym} page"; share (system share sheet with the report link).
5. **Chat history:** list from `/v1/chat-history` (cursor), tap → load the session (`GET /:id` blocks) or the report; swipe to archive/delete (`PATCH /:id/archive`, `DELETE /:id`).
6. **Guardrails/copy:** every answer bubble ends with the advisory footer when the server marks it (existing `message-advisory-gate` semantics arrive as a block); no numbers are computed on the client.

## Non-goals
Voice input, image attachments, memory chip (W15/M19 later), analyst board (later).

## Acceptance
- A streamed turn renders token-by-token on both platforms from QA; cancelling mid-stream stops rendering and the server call (A01 spy); a dropped connection retries without duplicating the message.
- Research flow: confirm shows the server estimate; running a research on INFY consumes exactly the charged credits per `/v1/credits` before/after; the report renders every `ContentBlock` kind from a fixture session (render tests per block).
- Out-of-credits path never hits `POST /v1/research` (test).
- Model sheet shows locked rows for a non-allowlisted user; selecting Flash changes the estimate multiplier.
- Screenshots (empty, streaming, report, history; light/dark); `verify:push`; `/code-review ultra` (credits).
