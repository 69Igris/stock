## Architecture law (enforced by lint, not by convention)
- Mobile never imports `@usemoney/database`, `@usemoney/services`, `@usemoney/core` (server), anything under `apps/web` or `workers`. Allowed: `@usemoney/types` (types only), and `@usemoney/validation` / `@usemoney/utils` **only after** proving they are RN-safe (no `node:*`, no Prisma); otherwise copy the minimal Zod schemas into `apps/mobile/src/contracts/` and add a contract test in `apps/api/__tests__` that compares them with the server schemas.
- Every byte comes from `apps/api` `/v1` with a Clerk JWT. Broker OAuth and payments never handle secrets in the app.

## Build
1. **Scaffold** `apps/mobile` (`@usemoney/mobile`, `private`): latest stable Expo SDK with the New Architecture, TypeScript strict (extends `@usemoney/typescript-config`), **Expo Router** (file-based, typed routes), `expo-dev-client`. Metro config for Yarn-1 monorepo (`watchFolders` = repo root, `nodeModulesPaths` both levels, `disableHierarchicalLookup`); path alias `@/`. Continuous Native Generation: `ios/` and `android/` are **gitignored** and produced by `npx expo prebuild --clean`; `app.config.ts` holds everything native-config (bundle id `ai.usemoney.app` / package `ai.usemoney.app`, scheme `usemoney`, associated domains/intent filters for `https://usemoney.ai/app/*`, plugins: `expo-secure-store`, `expo-web-browser`, `expo-notifications`, `expo-local-authentication`, `expo-document-picker`, `expo-font`, `expo-build-properties`, `expo-splash-screen`, `expo-linking`, `expo-sharing`, `expo-clipboard`, `react-native-mmkv`, `@gorhom/bottom-sheet`, `react-native-reanimated`, `react-native-gesture-handler`, `react-native-svg`, `@shopify/flash-list`, `lucide-react-native`, `posthog-react-native`, `@datadog/mobile-react-native` (optional, flag)). Environments via `EXPO_PUBLIC_*` + `app.config.ts` `extra` (`qa`, `prod` profiles; `APP_ENV` switch); no secrets in the bundle.
2. **Turborepo wiring:** `apps/mobile` scripts `dev` (`expo start --dev-client`), `lint`, `type-check`, `test` (jest-expo + `@testing-library/react-native`), `prebuild`, `ios`, `android`; add to `turbo.json` pipelines for lint/type-check/test only (no `build`); root `yarn test` includes it; `TEST-COVERAGE.md` gains a Mobile section (`scripts/gen-test-coverage.ts` must learn the jest glob — extend it).
3. **ESLint:** `packages/eslint-config/react-native.js` + `no-restricted-imports` for the forbidden packages/paths; CI fails on violation.
4. **Auth:** `@clerk/clerk-expo` with `expo-secure-store` token cache; `ClerkProvider` in the root layout; `useAuth().getToken()` feeds the API client (`Authorization: Bearer`); sign-out clears MMKV caches + deregisters the push token (A01). Same Clerk instance as web.
5. **API client** `src/api/`: typed `fetchJson<T>(path, init)` unwrapping `{ success, data, error, meta }` into `T` or throwing `ApiError{code,message,status,requestId}`; `X-Request-Id` captured for support; ETag cache (MMKV) + `If-None-Match`; cursor pagination helper (`meta.nextCursor`); `streamSse(path, body, onEvent)` built on `expo/fetch` streaming (WinterCG `ReadableStream`; fall back to `react-native-sse` only if a platform lacks streaming — document why) parsing the A01 event schema; rate-limit/429 backoff; 401 → refresh token once → sign-out.
6. **State:** TanStack Query v5 (`QueryClient` with MMKV persister for offline-first reads; `staleTime` per resource: quotes 10 s, holdings 60 s, static 1 d), Zustand `useUmStore` mirroring `root2.jsx` `um`: `{ sheet, toast, searchOpen, sagePrefill, usFlag (from server flags), persona, plan, credits }` — UI-only; all server truth lives in queries.
7. **Theme + fonts:** `src/theme/tokens.ts` generated from `styles/colors_and_type.css` (light `:root` + `html.dark` sets; pop accents; text-safe variants; radii; hard shadows expressed as offset views on RN), `useTheme()` with system + manual override (persisted); fonts via `@expo-google-fonts/{inter,instrument-serif,jetbrains-mono}`; `Num` uses `fontVariant: ["tabular-nums"]`; money formatters (`money`, `signMoney`, `pct`, `inr`, `compactINR`, `usd`) ported from `app/data.js`/`src/shared.jsx` into `src/format/` with tests (en-IN lakh/crore grouping, en-US).
8. **Kit** `src/ui/`: port `kit2.jsx` + `shared.jsx` primitives 1:1 (names kept): `Screen`, `SubPage`, `PageHead`, `Card`, `Press`, `Seg`, `Chip`, `Tag`, `CreditChip`, `CostChip`, `Num`, `StatCell`, `BrokerLogo`, `SymTile`, `LineChart` (react-native-svg), `Donut`, `HBar`, `Spinner`, `ProgressSteps`, `EmptyState`, `Sheet` (gorhom), `Toast`, `SyncPill`, `GateBanner`, `SecHead`, `RowItem`, `ListCard`, `PullRefresh` (RefreshControl), `StarBtn`, `Sticker`, `Eyebrow`, `PrimaryBtn`, `GhostBtn`, `Field`, `StepBar`, `Wordmark`, `BrandMark`, `Icon` (lucide), `OAuthBtn`, `ClerkRow`, `Dots`, `EodTag`, `Disclaimer`, `SrcBadge`, `StatusChip`. Each with a render test; a `ui-gallery` dev route renders them all in light/dark for visual QA (screenshot in the PR).
9. **Navigation skeleton** (M10 fills it): `app/(public)/…` (splash, onboarding, welcome, auth, first-run, marketing/legal), `app/(app)/(tabs)/{index,portfolio,sage,discover,you}` (5 tabs, Sage centre), `app/(app)/…` pushes (stock/[symbol], mf/[id], compare, sector/[id], import, roast, fire, calculators, risk, tax, documents, brokers, notifications, plan, settings, invite, help, feedback, us/…, screener2, strategies, strategy/[id], homepresets, devsettings). Deep links: `usemoney://stock/INFY`, `https://usemoney.ai/app/stock/INFY`, push payload routes (A01). Guards: unauthenticated → `(public)`; authenticated without broker → first-run; demo mode banner.
