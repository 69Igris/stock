- Web sources of truth for copy and data (the mobile screens must not drift from them): `apps/web/app/(marketing)/{features,integrations,pricing,alternatives,security,about,roadmap,changelog}/page.tsx` (+ `changelog/releases.tsx` — release notes data; roadmap items), `apps/web/app/(public)/{blog,docs,glossary,newsletter,legal,privacy,terms,risk-disclosure,data-usage,subprocessors,unsubscribe}/*`, `packages/services/src/content.service.ts` (`getBlogPosts`, `getBlogPostBySlug`, `getDocs`, `getDocBySlug`, `getGlossaryPosts`, `getGlossaryPostBySlug`, `getNewsletters`, `getNewsletterBySlug`, `getTags`, gated variants), `apps/web/app/api/newsletter/{subscribe,unsubscribe,verify}`, `apps/web/app/api/email/preferences/*`, `packages/core/src/subscription/plans.ts` (pricing tiers/features — never hardcode prices), `apps/api/src/routes/v1/learning.ts` (`GET /glossary` exists), `apps/api/src/middleware/auth.ts` (`optionalAuthMiddleware` for public routes)
- Store rules: privacy policy + terms must be reachable in-app before sign-in (M02/M01 checklists) → the Legal hub is required.

## Build
1. **API (public, `optionalAuthMiddleware`, cached):** add a `/v1/content` family (or mount under `/v1/learning` to keep the family count — decide, document, update the count tests if needed): `GET /posts?cursor=&tag=`, `GET /posts/:slug`, `GET /docs`, `GET /docs/:slug`, `GET /glossary` (reuse), `GET /glossary/:slug`, `GET /newsletters`, `GET /newsletters/:slug`, `GET /changelog` (from `releases.tsx` moved into a shared data module — `packages/core/src/marketing/releases.ts` — so web and API read one source), `GET /roadmap` (same treatment), `GET /legal/:doc` (privacy · terms · risk-disclosure · data-usage · subprocessors — markdown/HTML served from one source the web pages also render; move the copy into `packages/core/src/legal/*.md` if it lives in TSX today), `POST /newsletter/subscribe`, `POST /newsletter/unsubscribe` (token), `GET /pricing` (plans + features + prices from `plans.ts`). Gated content (`getGated*`) returns the teaser + `gated: true` for signed-out users.
2. **Explore hub** (`/more`): groups/rows exactly as `MoreScreenV2`; footer CTA → sign-up.
3. **Marketing screens (static copy from the web pages, rebuilt with the kit — headline/serif/sticker voice):** Features (feature blocks with kit visuals), Broker sync (broker grid from `assets/brokers/*`, read-only OAuth explainer, "8 brokers" count from the server catalog), StockSage (marketing explainer + demo answer card), Pricing (tiers from `/v1/pricing`; **no purchase buttons here on iOS/Android beyond "Create free account" — purchases happen in You → Plans via IAP (A02/M19)**; the "50% off" style copy only if the server says so), Why UseMoney (comparison table from `alternatives`), Security (from the security page), About, Roadmap (`/v1/roadmap`), Changelog (`/v1/changelog`).
4. **Content screens:** Blog list + post (markdown → RN renderer with the kit typography; images; tags; related), Docs list + doc, Glossary list + term (+ deep link from Sage citations), Newsletter list + issue + subscribe form (`POST /subscribe` → "check your email" state), Unsubscribe (token from a deep link `https://usemoney.ai/app/unsubscribe?token=` → `POST /unsubscribe`), gated posts show the teaser + sign-up CTA.
5. **Legal hub + docs:** hub rows (Privacy · Terms · Risk disclosure · Data usage · Subprocessors · Email preferences) → `LegalDoc` renderer (server markdown; last-updated date; share/open-on-web); reachable from Welcome/Sign-up footers and You → About & legal.
6. **404:** friendly not-found for unknown deep links with "Back to Home".
7. **Public-group chrome:** `Screen` with top padding/back button per design; everything works signed-out; signed-in users get the same screens without the sign-up CTAs (replaced by "Back to app").

## Non-goals
Comments, search across content (later), push for new posts, marketing A/B copy.

## Acceptance
- Every hub row opens a native screen (no WebViews — test); all copy/data comes from the shared sources (contract tests: `/v1/pricing` equals `plans.ts`; `/v1/changelog` equals the web releases module; legal docs byte-equal the web versions).
- Blog/docs/glossary/newsletter render QA content incl. images and gated teasers; subscribe/unsubscribe round-trip on QA.
- Privacy and Terms reachable in ≤ 2 taps from the Welcome screen while signed out (store requirement).
- Screenshots (hub + 8 marketing + 4 content + legal; light/dark); `verify:push`; `/code-review`.
