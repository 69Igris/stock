## Build
1. **You hub:** groups per design; badges from live data (brokers attention, plan, US persona from `/v1/me`); dark toggle (theme override); sign out (Clerk `signOut` → `DELETE /v1/devices/:token` → clear MMKV); version line from `expo-constants`.
2. **Brokers:** cards from `/v1/brokers` + `/counts` + `/sync-status` (LIVE / EXPIRED / SYNCING), Sync now (`POST /:id/sync` → poll job), Reconnect (M11 OAuth flow with `ctx=manage` → back to this screen + toast), Disconnect (confirm sheet copy → `DELETE /:id`), Add a broker (India tiles → consent + OAuth; US tiles/import when flag → M20), Upstox daily-token note when applicable (from the broker catalog metadata, not hardcoded), footer.
3. **Notifications:** list (cursor) with unread dots, tap → deep link (`n.go`/payload route), Mark read (`POST /read-all`), swipe → read; US rows when flag; pull-to-refresh; push permission prompt entry point ("Get notified" banner when permission is undetermined) → `expo-notifications` request → `POST /v1/devices`.
4. **Plans & credits (native IAP):** plan cards from `GET /v1/subscription/store/products` (names/features from the server plan definitions; prices from the store product info via the IAP library — never typed), cycle toggle maps to monthly/yearly products, "Get {plan}" → platform purchase sheet → on success `POST /v1/subscription/store/{apple|google}` with the transaction/token → success screen (credits from the response) → "Spend one on deep research" → Sage; "Restore purchases"; "Manage subscription" → platform subscription settings; current-plan state, cancel/downgrade info from `/v1/subscription`; Dodo-managed subscriptions (web) show "Managed on the web" with a link (allowed: informational, no purchase link for digital goods on iOS — keep it a plain "Manage on usemoney.ai" without price/upsell copy to respect 3.1.1).
5. **Settings & privacy:** Account (name/email/phone from Clerk), Security (2FA TOTP enrol/disable via Clerk, change password, active sessions list + revoke, biometric unlock toggle), Markets (flag → M20 prefs/accounts), Sage memory (list/delete/delete-all via W15 endpoints; if W15 is not shipped, hide the section behind its flag — never a fake list), Data (Export everything → `POST /v1/me/export` if present else omit; Delete account → OTP flow `POST /v1/me/delete-otp` → `DELETE /v1/me` with the 30-day grace copy — **required by both stores**), Alerts preferences (notification categories → `PATCH /v1/devices/:token`).
6. **Invite / Help / Feedback:** invite code + share sheet + invited list (from the invite API), FAQ (static copy from design; "Email us" → mail link), feedback (`POST /v1/feedback` with kind + text; thread view for replies).

## Non-goals
Web checkout, coupon redemption in-app (store rules), admin features.

## Acceptance
- Brokers: sync/reconnect/disconnect round-trip on QA with correct pills; the disconnect confirm copy verbatim.
- Notifications: unread → read persists; push permission requested only from the banner; device registered/deregistered on login/logout (API spy).
- IAP: sandbox purchase (iOS) and test purchase (Android) update the plan + credits via A02; Restore works; a failed receipt shows the server error code; no in-app price strings hardcoded (test).
- Account deletion OTP flow completes on QA; sign out clears local data (MMKV empty).
- Screenshots (hub, brokers, notifications, plans, settings, invite, help, feedback; light/dark); `verify:push`; `/code-review ultra` (billing + auth).
