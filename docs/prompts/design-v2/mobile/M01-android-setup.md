## Build
1. **Toolchain (document exact versions in `apps/mobile/CLAUDE.md` on first successful build):** Temurin JDK 17, Android Studio (latest stable) with SDK Platform for the Expo SDK's `compileSdkVersion`/`targetSdkVersion` (Google Play requires targeting the latest-1 API within a year of release — set via `expo-build-properties`), Build-Tools, NDK if any dep pulls it, an emulator image (Pixel 8, API 35+, Google APIs), `ANDROID_HOME`/`JAVA_HOME` in the shell profile; `adb` on PATH. Gradle wrapper pinned by Expo; commit `android/gradle.lockfile` **is not possible with CNG** — instead pin dependency versions in `package.json` and record `gradle -v` output in CLAUDE.md.
2. **App config (Android section of `app.config.ts`):** `package: "ai.usemoney.app"`, `versionCode` from CI env (`ANDROID_VERSION_CODE`, monotonic), adaptive icon (foreground from the U mark, background `#f7f3e6`; monochrome layer), splash (paper background, mark), `permissions` minimal (INTERNET, POST_NOTIFICATIONS, USE_BIOMETRIC, CAMERA **not** requested — statement upload uses the document picker), `intentFilters` for `https://usemoney.ai/app/*` (autoVerify) + scheme `usemoney`, `edgeToEdgeEnabled`, `softwareKeyboardLayoutMode: "pan"`, `allowBackup: false`, 16 KB page-size compatible builds (`expo-build-properties` → `android.enable16kPageSizes` or the SDK's equivalent — verify current key), `useLegacyPackaging: false`.
3. **Digital Asset Links:** add `apps/web/public/.well-known/assetlinks.json` with the release signing cert SHA-256 (and the debug cert for QA builds) so `https://usemoney.ai/app/*` opens the app; verify with `adb shell pm get-app-links ai.usemoney.app`.
4. **FCM:** create the Android app in the existing Firebase/GCP project, download `google-services.json` into `apps/mobile/` (gitignored; CI injects from Secret Manager), add `@react-native-firebase/app` **only if** `expo-notifications` alone cannot deliver FCM data messages for the A01 payloads — prefer `expo-notifications` with FCM V1 credentials; notification channels (`signals`, `research`, `brokers`, `billing`, `general`) with the design's sound/importance; deep-link handling on tap → Expo Router (`usemoney://…`); test with the A01 QA event.
5. **Signing:** generate an **upload keystore** (`keytool -genkeypair … -validity 10000`), store it outside the repo (`~/.android/usemoney-upload.jks`) with `~/.gradle/gradle.properties` holding `USEMONEY_UPLOAD_STORE_FILE/STORE_PASSWORD/KEY_ALIAS/KEY_PASSWORD`; wire via an Expo config plugin that writes `signingConfigs.release` at prebuild time (never commit secrets); enrol in Play App Signing (Google holds the app signing key). Debug builds keep the default debug keystore.
6. **Builds:** `npx expo prebuild --platform android --clean` → `npx expo run:android` (debug, emulator + USB device with `adb reverse tcp:8081`), `cd android && ./gradlew bundleRelease` (AAB) and `./gradlew assembleRelease` (APK for sideload QA); R8/ProGuard enabled with the Expo defaults + rules for `react-native-mmkv`/`reanimated`; `hermes` on; verify the release AAB boots on the emulator via `bundletool build-apks --local-testing`.
7. **Play Billing (A02 client prerequisites):** add the Play Billing dependency through the chosen IAP library (`expo-iap` preferred if maintained for the current SDK, else `react-native-iap` — record the decision), create the products in Play Console (ids from `packages/core/src/subscription/store-products.ts`), license testers, RTDN Pub/Sub topic wired to A02's webhook.
8. **Play Console readiness checklist** (`docs/reference/mobile-store-android.md`, generated, not submitted): app listing copy (from `src/screens-marketing.jsx` voice), screenshots per device class (from the design frames), feature graphic, content rating questionnaire, **Data safety** form (data collected: email, name, financial info (portfolio holdings — user-provided/synced), device id for push; encrypted in transit; deletion available in-app — Settings → Delete account), Financial features declaration (no lending/trading — analysis only), target audience 18+, privacy policy URL `https://usemoney.ai/privacy`, account deletion URL, internal testing track → closed testing (12 testers × 14 days requirement for personal developer accounts — confirm the org account status).
9. **CI (later, Cloud Build):** `cloudbuild.android.yaml` skeleton that runs prebuild + `bundleRelease` on a Linux builder with the secrets from Secret Manager; not required to pass now, but committed.

## Non-goals
Store submission itself, EAS, Huawei/other stores, tablets/foldables layouts (phone-first; must not crash on tablets).

## Acceptance
- Fresh clone → documented commands produce a debug build running on the emulator and on a physical device; release AAB builds and boots via bundletool; `apps/mobile/CLAUDE.md` records JDK/SDK/NDK/Gradle/Android Studio versions.
- `assetlinks.json` verified (`pm get-app-links` shows `verified`); a tapped `https://usemoney.ai/app/stock/INFY` link opens the stock route.
- A QA push (A01) arrives on the emulator with the right channel and deep-links on tap; token registered on `/v1/devices`.
- Release build has no debug logging, `allowBackup=false`, and passes `bundletool validate`.
- Checklist doc committed; `verify:push` green (lint/type-check/test — no native build in the gate); `/code-review`.
