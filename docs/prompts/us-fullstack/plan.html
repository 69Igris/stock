One function, two callers

Your rule from today, written into the shared context and enforced by MONEY-1632: each feature is one function in packages/services. The Next.js app reaches it through a server action; the future mobile app reaches the same function through /v1/us/*. A registry lists every surface and a test fails when either caller is missing, or when either has its own implementation.
