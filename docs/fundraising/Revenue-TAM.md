| SEBI RIA gap       | <1,000 RIAs for 136M investors          | AI advisory isn't a luxury - it's the only way to scale advice        |

### The B2B multiplier is key

Consumer SaaS alone gets you to ~$42M. The **B2B API licensing** ($36.7M) is the
lever that pushes to $100M. This is the same playbook as Plaid (API for banking)
and Smallcase (embedded investing API for brokers). Smaller brokers like Fyers,
Dhan, 5paisa, and new-age neobanks all need AI-powered analysis tools but won't
build them in-house. usemoney becomes their AI engine.
