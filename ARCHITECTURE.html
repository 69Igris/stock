etf-expense-enrichment

RETIRED (MONEY-1404). The processor is deleted; the route survives and answers 200 {retired:true}, same reason as financial-data-sync — Pub/Sub ACKs only on 2xx, so a 410 or a deleted route's 404 NACKs and burns five delivery attempts plus a dead-letter per message until setup-scheduler.sh prod removes the live weekly trigger. It could never write: fetchKuveraMetadata returns null unless MF_METADATA_PROVIDER === "kuvera" and both specs set "amfi". expenseRatio now comes from AMFI's own monthly TER file via mf-metadata-sync.

financial-data-sync (retired)

RETIRED (MONEY-1220). Its only source was Tickertape, which now returns 403 to our Cloud Run egress (200 from a laptop) — a permanent, silent block. The processor is deleted; the route survives and answers 200 {retired:true} rather than 410 or 404, because Pub/Sub ACKs only on 2xx — any other status NACKs and burns five delivery attempts per message until the live scheduler is deleted.

14How to add X

Concrete recipes for common changes.

Add a new broker
  1. Create HTTP client in packages/core/src/brokers/clients/<broker>.ts
  2. Create adapter in packages/core/src/brokers/adapters/<broker>.ts conforming to the existing interface (holdings, positions, trades, [mf])
  3. Register it in packages/core/src/brokers/adapters/index.ts
  4. Add OAuth callback at apps/web/app/api/brokers/<broker>/callback/route.ts
  5. Add UI affordance under apps/web/app/brokers
  6. Document API quirks in MEMORY.md ([[project_broker_api_findings]])
  7. Encrypt tokens via packages/security - never store plaintext

15Conventions

Non-obvious rules. Most are enforced by hooks / CI - others are tribal.

Branch naming

Strict {type}/MONEY-{number} only. No text suffix. Enforced by Husky pre-push and GitHub Actions.

Enforced

Never commit unless asked

Don't git add or git commit unless the user explicitly asks. Don't push without asking.

User rule

yarn build before commit on source changes

Next.js build catches type errors that tsc --noEmit accepts (factory-vs-instance import confusion).

Theme-aware styling

Never hardcode dark RGBA values; use CSS vars or dark: prefix. Test in both themes.

TEST-COVERAGE.md is single source of truth

Any test add/remove/change updates it in the same PR (counts + per-section tables).

scripts/README.md must stay current

Any change in scripts/ (add/rename/remove/flag) requires a README row update in the same PR.

apps/api mirrors server actions

Whenever you add or change a server action with mobile relevance, mirror it in apps/api/src/routes/v1.

No direct Prisma from components or actions

All DB work goes through packages/services/*.service.ts.

Sanitize errors before user-facing

DB/system errors must be mapped via packages/core error helpers; detailed logs stay server-side.

Demo flow must survive UI redesigns

Landing/hero changes preserve Try Demo CTA. Use window.location.href (not router.push) and set tradebook_demo_mode localStorage flag.

Datadog APM on Vercel: OFF

Only Cloud Run gets DD_TRACE_ENABLED=true. Vercel uses RUM + HTTP logs only.

Atlas Search is prod-only

QA/dev hit DigitalOcean Mongo which doesn't support $search. Screener uses dual-path: Atlas in prod, regex in QA.

Don't gate user queries on freshness fields

Don't filter on lastSyncedAt/navDate. Trust upstream isActive flags; do cleanup in sync layer.

Chat must degrade gracefully

Credit/quota walls return 200 + ErrorBlock(warning) + NavigationBlock(upgrade CTA), never bare 403. Flash chat is ungated for FREE.

dist-clean protects tracked dist/

UDF bundle.js is git-tracked; yarn dist-clean walks each dist/ and skips ones with git-tracked files.

TradingView chart sync is explicit

postinstall is gated behind SYNC_CHARTING_LIBRARY=1. Bare yarn install is a no-op for charting.
