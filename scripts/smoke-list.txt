# scripts/smoke-list.txt
# -----------------------------------------------------------------------------
# SMOKE TIER manifest — the critical-path test subset (`yarn test:smoke`).
#
# Each non-blank, non-`#` line is a WORKSPACE-RELATIVE glob (forward slashes).
# `scripts/run-smoke.ts` reads this file, groups globs by their leading
# workspace directory (e.g. `apps/web`, `packages/core`), and spawns ONE
# `node --import tsx --test` per workspace WITH THAT WORKSPACE AS CWD so the
# `@/*` tsconfig alias and `../../` relative imports resolve exactly as they do
# under the per-workspace `yarn test`.
#
# RULES:
#   - Keep this list FAST (whole `test:smoke` budget is < 60s) and STABLE: only
#     pure / mocked tests (no live network, no DB, no Redis). Contract tests use
#     undici MockAgent and stay pure.
#   - One glob per line. Globs may use `*` and `**`. A literal file path is fine.
#   - The leading path segment(s) up to `__tests__` must be a real workspace dir.
#   - When you ADD/REMOVE a smoke entry, update scripts/README.md.
#
# Scope (per MONEY-620): FIFO pairing · calc-suite · guardrails ·
# webhook signature/idempotency + the *-e2e routes · demo routes ·
# security/* (encryption, IDOR, SSRF, cron-auth, credit-atomic, rate-limit) ·
# subscription access · contract tests.
# -----------------------------------------------------------------------------
