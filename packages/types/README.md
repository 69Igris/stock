# @usemoney/types

> Shared TypeScript type definitions for UseMoney

## Usage

```typescript
import { User, Trade, Holding } from "@usemoney/types";
import { UserProfile } from "@usemoney/types/user";
import { TradeData } from "@usemoney/types/trade";
import { BrokerType } from "@usemoney/types/broker";
import { PUBSUB_TOPICS, getTopicName } from "@usemoney/types/pubsub";
```

## Type Categories

| Path            | Description                            |
| --------------- | -------------------------------------- |
| `/user`         | User and profile types                 |
| `/trade`        | Trade types                            |
| `/holding`      | Holding types                          |
| `/broker`       | Broker connection & config types       |
| `/mutual-fund`  | Mutual fund types                      |
| `/analysis`     | Analysis report types                  |
| `/subscription` | Subscription plan types                |
| `/fire`         | FIRE calculator types                  |
| `/paper`        | Paper trading types                    |
| `/dashboard`    | Dashboard stats & portfolio types      |
| `/pubsub`       | Pub/Sub topics, message types, helpers |
| `/research`     | Research session & status types        |
| `/roast`        | Portfolio roast result types           |
| `/chat`         | Chat content blocks & context types    |
| `/gemini`       | Gemini LLM integration types           |
| `/learning`     | Course, chapter, lesson, quiz types    |
| `/content`      | Blog, glossary, newsletter, CMS types  |
| `/comparison`   | Fund comparison types                  |
| `/common`       | ApiResponse, ActionResponse, Paginated |
