# @usemoney/ui

> Shared UI components for UseMoney

Built with shadcn/ui, Radix primitives, and Tailwind CSS.

## Usage

```typescript
import { Button, Card, Input } from "@usemoney/ui";

<Card>
  <CardContent>
    <Input placeholder="Value" />
    <Button>Submit</Button>
  </CardContent>
</Card>
```

## Components

- **Layout:** Card, Dialog, Sheet, Tabs
- **Form:** Button, Input, Select, Checkbox
- **Display:** Badge, Avatar, Skeleton
- **Feedback:** Toast, Alert, Progress
