# @usemoney/typescript-config

> Shared TypeScript configuration for UseMoney

## Usage

```json
{
  "extends": "@usemoney/typescript-config/next.json"
}
```

## Configs

- `base.json` - Base config
- `next.json` - Next.js apps
- `react-library.json` - React packages
- `node.json` - Node.js packages
